# NowNow 개발 공유 | 11월 4일 이후

11월 4일 팀 main의 인증·API 연결 및 홈 취향 기능을 기준으로 이어서 작업했습니다. 이 문서는 11월 7일까지 작업 브랜치에 반영한 변경과 통합 테스트 범위를 정리합니다.

## 추가·수정한 기능

| 영역 | 변경 내용 |
| --- | --- |
| 인증과 저장 | 로그인한 사용자의 Supabase 토큰을 팀 API에 전달합니다. 서버가 계정을 확인하고 대화와 요약을 해당 계정으로 저장·조회합니다. 오늘 대화 복원과 채팅 입력창의 키보드 대응도 다듬었습니다. |
| 건강 기록 상담 | **오늘의 건강기록♡** 버튼과 건강 질문에 계정의 건강 기록을 조회해 응답에 활용합니다. 기록이 부족한 경우를 처리하고, 최근 대화와 사용자 취향을 참고합니다. 워치에서 읽은 건강 기록의 동기화는 리포트의 기존 흐름에서 처리합니다. |
| 감정일기와 키워드 | 스트레스 표현에는 공감과 원인 질문을 먼저 하고, 기쁜 대화에는 취미나 즐길 거리를 제안합니다. 하루 정리에서 자동 분류하며 작품·졸작은 학업에 포함합니다. 원인 단서가 없을 때는 일상을 사용합니다. 직접 입력한 키워드는 즉시 저장하고 같은 대화의 요약은 갱신합니다. 요약 시각을 기록해 오늘·어제와 주간 리포트의 키워드 집계에 반영합니다. |
| 뿡뿡이 대화 | 다정한 반말과 가끔 이모티콘을 쓰도록 조정했습니다. 휴식·명상 영상·동물 이미지·음식과 배달 앱·음악·영화 등 대화에 맞는 행동을 안내합니다. 영화 링크는 CGV와 메가박스, 음악 링크는 추천 곡과 가수 검색으로 연결합니다. |
| 리포트 | 걸음수·수면의 일일 그래프를 추가하고 심박·혈압 화면과 차트 스타일을 맞췄습니다. 최근 기록과 원인 키워드를 기반으로 AI 추천을 요청하며, 서버에 연결할 수 없으면 기본 추천을 표시합니다. 실시간 스트레스 분석은 오늘의 측정 기록을 기준으로 최고·최저 시간과 점수를 표시합니다. |
| 혈압 | 리포트 혈압 카드에서 수축기·이완기 혈압을 직접 입력해 계정에 저장합니다. **내 설정 → 웰니스 → 혈압계 연결**에는 준비 중 안내를 넣었습니다. |
| 프로필과 권한 | 계정 설정에서 별명·성별·나이와 이메일·비밀번호 항목을 확인할 수 있습니다. 별명은 채팅 답변과 알림에 각각 약 25% 확률로 사용합니다. MBTI와 활동·음식·음악 취향, 개인정보 보호의 건강 데이터 권한과 앱 권한 진입도 추가했습니다. |
| 알림 | 하루 마무리·날씨·놀자·안부 알림을 알림 설정에 모았습니다. 놀자 알림은 평일·주말·매일 중 선택하며 오전 9시·낮 12시·오후 5시를 사용합니다. 날씨 지역에 인천과 안양을 추가했습니다. |

## 검증과 남은 작업

- TypeScript 검사 및 백엔드 자동 테스트 35개를 통과했습니다. S24에서 최신 APK 설치와 앱 실행, USB를 통한 PC 서버 연결을 확인했습니다.
- 공용 테스트 계정에서 요약 저장, 같은 요약에 사용자 키워드 추가, 오늘 리포트 집계까지 실제 Supabase로 확인했습니다. 확인용 기록은 정리했습니다.
- 저장된 요약의 벡터 검색은 선택 기능입니다. 별도 SQL 마이그레이션과 서버 임베딩 키 설정이 필요하며, 팀 DB의 마이그레이션 적용 및 실제 검색 검증은 별도 단계입니다. 건강 기록 상담의 기본 조회는 날짜와 항목을 기준으로 합니다.
- 실시간 스트레스 화면에는 기존 팀 계산식이 사용됩니다. HRV 없이 쓸 새 지표는 별도 논의 대상입니다. 블루투스 혈압계 실측 수신과 알림 별명 표시의 실기기 확인도 남아 있습니다.
- 현재 S24 검증은 USB 테스트 서버 기준입니다. USB 없이 검증하려면 팀 백엔드를 테스트 계정만 접속할 수 있도록 HTTPS로 배포하고, 안드로이드 빌드에 `nownowApiBaseUrl`을 지정해야 합니다. 서버 키는 배포 환경의 비밀 변수로 설정합니다.

## 통합 확인 순서

1. 테스트 계정으로 로그인하고 오늘의 건강기록 버튼과 일반 채팅을 확인합니다.
2. 하루 정리에서 키워드를 직접 추가하고 리포트의 오늘 탭에 집계되는지 확인합니다.
3. 리포트의 AI 추천과 연결이 끊겼을 때의 기본 추천을 확인합니다.
4. 혈압 직접 입력, 별명 저장, 알림과 권한 화면을 확인합니다.
